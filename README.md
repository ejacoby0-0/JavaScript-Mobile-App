# JavaScript-Mobile-App

## Project Overview
This project is an Android mobile application 

The purpose of this project is to provide an opportunity to unify travel documentation and planning into a seamless, multimedia-rich experience for users touring their own country or other countries.

## Tech Stack
1. Frontend/Languages: XML
2. Backend: JavaScript
3. IDE: Android Studio

## Features
1. User Registration and Login with basic profile setup
2. Memory Creation Activities allowing users to post text, images, and background music
3. Gallery View Activity that presents memories in a visual timeline or grid
4. Trip Planning Activity where users can:
    - Select activities
    - Estimate travel budgets
    - Apply loyalty discounts after a certain number of trips
5. Budgeting Calculator with real-time cost updates and summaries
6. Persistent Storage of trip histories, memory entries, and user preferences
